# Video Saver Bot

Бот принимает ссылки из:
- YouTube / YouTube Shorts
- Instagram Reels / видео-посты
- TikTok

Пользователь просто отправляет ссылку, а бот скачивает открытое видео и отправляет его в Telegram.

## Запуск

1. Установи Python 3.11+.
2. Переименуй `.env.example` в `.env`.
3. Вставь токен бота:

```env
BOT_TOKEN=твой_токен
MAX_MB=45
```

4. Запусти `run_bot.bat` или вручную:

```bash
pip install -r requirements.txt
python bot.py
```

## Важно

Бот не обходит приватные аккаунты, авторизацию, платный контент и закрытые видео. Используй его только для контента, который тебе разрешено сохранять.
